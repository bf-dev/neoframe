# Neowiki Static Website

This is a static website built with Next.js for Neowiki.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build Static Site

```bash
npm run build
```

This will generate a static export in the `out` directory.

## Deployment

This website is deployed to [neowiki.one](https://neowiki.one) using GitHub Pages.

## Tech Stack

- Next.js 15.3.0
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
